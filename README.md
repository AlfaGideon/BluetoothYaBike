# BluetoothYaBike

Android-приложение для исследования BLE-обмена с умным велосипедом Яндекс Байк (IoT-модуль),
с автоматической сборкой APK в GitHub Actions. Работает без интернета на телефоне:
всё, что делает приложение, — это Bluetooth (скан → GATT → кадры).

## Что уже есть

| Возможность | Где |
|---|---|
| Скан BLE с рекламными данными (MFR/SvcData/RSSI), фильтр «только с именем» | главный экран |
| Автоподключение по тапу, повтор при ошибке 133 | `BikeBleClient` |
| Дамп GATT-дерева: сервисы, характеристики, свойства R/W/N/I, дескрипторы | кнопка «GATT» |
| Подписка на все notify/indicate, чтение всех читаемых характеристик | автоматически после коннекта |
| Hex-журнал TX/RX с временем и ASCII-расшифровкой | нижняя половина экрана |
| Запись произвольного кадра: в выбранную характеристику или во все writable сразу | поле hex + «Отправить» |
| Тест-кадры (00/01/02/03/FE/FF/AA 55/…), повтор последнего RX | «Тест-кадры», «Повторить RX» |
| Экспорт журнала в `.txt` через «Поделиться» | «Экспорт» |

APK собирается на каждый push и лежит в **Actions → нужный запуск → Artifacts**.

## Главное ограничение

В публичном доступе **нет** описания Bluetooth-протокола Яндекс Байка. Официальное приложение
Яндекс Про разблокирует байк по BLE без интернета (это подтверждают разработчики Яндекса),
но кадры авторизации/разблокировки генерируются в приложении и привязаны к аккаунту и
конкретному байку. Поэтому:

1. Приложение сейчас — **инструмент исследования**: оно показывает, какие каналы GATT есть у байка,
   что он присылает в эфир и как реагирует на записи.
2. Чтобы получить настоящую кнопку «Разблокировать», нужно один раз снять трафик официального
   приложения (Android HCI snoop log) и перенести найденные кадры в проект — пошаговый план
   в [docs/EXPERIMENT.md](docs/EXPERIMENT.md) и [docs/PROTOCOL.md](docs/PROTOCOL.md).
3. Скрипт для разбора snoop-лога: [tools/parse_btsnoop.py](tools/parse_btsnoop.py).

## Сборка

APK собирается автоматически (`.github/workflows/android.yml`), локально:
`./gradlew assembleDebug`, результат: `app/build/outputs/apk/debug/app-debug.apk`.
Сейчас release подписывается debug-ключом, чтобы APK из CI сразу ставился на телефон.
