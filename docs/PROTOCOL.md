# Протокол BLE Яндекс Байка — что известно

Документ ведётся по мере исследования. Пустые поля заполняются после записи трафика
(инструкция: [EXPERIMENT.md](EXPERIMENT.md)).

## Публично известное

- У байка есть IoT-модуль с **Bluetooth и Wi-Fi**; телеметрия уходит в облако по MQTT
  (Яндекс IoT Core) раз в ~10 секунд, объём ~500 байт.
- Разблокировка возможна **по Bluetooth без интернета** — это резервный канал для курьеров.
- Логика приложения — Яндекс Про (правообладатель сервиса аренды — ООО «ММ-Тех»).
- Источник: [dev.go.yandex/blog/yandex-bike](https://dev.go.yandex/blog/yandex-bike) (май 2025).
